## 实现计划

### 任务 1：修复列表展示 bug（文件大小显示在修改时间列）

**根因**：`FilePanel` 的排序表头有 3 列（名称 flex:1 / 大小 92px / 修改时间 120px），但 `FileEntryRow` 只渲染 2 个单元格（row-name / row-size 92px）。row-size 占据了最右位置，正好对齐表头的「修改时间」列，所以大小显示在了修改时间列下，且根本没有修改时间单元格。

**改动**（2 个文件）：

1. `frontend/src/components/FileEntryRow.tsx`
   - 在 `row-size`（92px）之后新增一个 `row-time` 单元格，渲染 `formatTime(entry.mod_time)`。
   - 新增 `formatTime(t)` 工具函数：`Date.parse` 解析 ISO 字符串，格式化为 `YYYY-MM-DD HH:mm`；解析失败或无值返回空字符串（目录和缺失时间都不显示）。

2. `frontend/src/style.css`
   - 新增 `.row-time { width: 120px; text-align: right; color: var(--mist); font-size: var(--fs-xs); }`，与 `.sort-time`（120px）对齐，与 `.row-size`（92px ↔ `.sort-size`）保持一致。

> 改后行结构：`icon | name(flex:1) | size(92px) | time(120px)` ↔ 表头 `名称 | 大小 | 修改时间`，列对齐修复。

### 任务 2：右键重命名

设备侧后端 `Rename(serial, oldPath, newPath)` 与前端绑定 `Rename` 已存在。本地面板需新增 `RenameLocal`。

**后端（2 个文件）**：

3. `internal/localfs/localfs.go`
   - 新增 `func Rename(oldPath, newPath string) error { return os.Rename(oldPath, newPath) }`。

4. `app_local.go`
   - 新增 `func (a *App) RenameLocal(oldPath, newPath string) error { return localfs.Rename(oldPath, newPath) }`。

5. 重新生成 TypeScript 绑定（`wails3 generate bindings -ts -d frontend/bindings .`，由 Taskfile `generate` 任务封装），使 `RenameLocal` 出现在 `app.ts`。

**前端（2 个文件，复用现有模式）**：

6. 新建 `frontend/src/components/PromptDialog.tsx`
   - 可复用的单行输入对话框，仿照 `ConfirmDialog`/`ConnectDialog` 结构（`.overlay/.dialog/.dialog-title/.dialog-input/.dialog-actions`），props：`open, title, initialValue, confirmLabel, onConfirm(text), onCancel`。内部用 `useState` 管理输入、`useEffect` 在 open 时重置为 initialValue 并自动聚焦/全选。空值时禁用确认按钮。

7. `frontend/src/App.tsx`
   - import `PromptDialog` 与 `Rename, RenameLocal`。
   - 新增状态 `pendingRename: { side: 'local'|'device'; entry: FileEntry } | null`。
   - 新增 `requestRename(side, entry)` 设置 `pendingRename`。
   - `buildMenuItems`：在「推送/拉取」与「删除」之间插入「重命名」项（`onSelect: () => requestRename(side, entry)`）——本地与设备两个菜单都加。
   - 新增 `confirmRename(newName)`：trim 校验非空且与原名不同；计算 `newPath`（保持原目录，替换 basename）；本地侧调 `RenameLocal(oldPath, newPath)`，设备侧调 `Rename(serial, oldPath, newPath)`；成功后清状态 + 刷新对应 pane；失败弹 `Toast`/`alert`。
   - 渲染 `<PromptDialog>`：title「重命名」，initialValue 取 entry.name，确认调 `confirmRename`。
